# Simulado CNH Goiás — V9

Plataforma aberta do CFC São Luiz.

## Princípios desta versão
- Sem login.
- Sem senha.
- Sem cadastro.
- O aluno entra pelo link e começa a estudar.
- O progresso do aluno permanece localmente no próprio navegador/aparelho.
- Mantidos banco de 1.500 questões, placas, simulados, estudo por assunto, treino personalizado, banco de erros, desempenho, evolução, XP e conquistas.
- Interface V8.2 preservada e aprimorada com chamada de acesso livre.

## Publicação
Este pacote é um site estático. Pode ser publicado em uma hospedagem de site estático para gerar um link público e ser compartilhado pelo WhatsApp.

Observação: projeto independente para estudo; não é um site oficial do DETRAN-GO.
