# Simulado CNH Goiás — CFC São Luiz

Plataforma independente de estudos para preparação teórica para a CNH em Goiás.

## Estado atual da aplicação

- 1.500 questões integradas ao index.html.
- 30 questões no Simulado Completo.
- 30 questões / 60 minutos no Simulado Prova.
- Simulado Rápido, Treino Personalizado, Estudar por Assunto e Praticar Meus Erros.
- Histórico e desempenho armazenados localmente no navegador.
- Regra de aprovação do simulado de 30 questões: 20 acertos ou mais.
- 88 códigos de placas efetivamente utilizados pelo banco e validados contra os arquivos existentes.
- 147 entradas na tabela PLATE_IMAGES, todas apontando para arquivos existentes.
- Domínio personalizado configurado no projeto por meio de CNAME: simuladocnhgoias.com.br.

## Auditoria atual do repositório — 30/09/2026

- IDs duplicados: 0
- Respostas fora do índice: 0
- Questões sem exatamente 4 alternativas: 0
- Códigos de placas usados com caminho quebrado: 0
- Referências de imagem locais quebradas: 0
- Sintaxe JavaScript: PASS
- Páginas legais: Política de Privacidade e Termos de Uso
- SEO: canonical, description, robots, Open Graph, Twitter Card e JSON-LD básicos
- Arquivos de rastreamento: robots.txt e sitemap.xml

## Monetização

Os espaços de anúncio já estão preparados, mas o código do Google AdSense e o ads.txt ainda dependem do ID de publisher fornecido pelo Google. Nenhum identificador de publisher é inventado no projeto.

## Avisos

O site não é oficial do DETRAN-GO. Os resultados dos simulados servem para estudo e acompanhamento e não garantem aprovação em prova oficial.
